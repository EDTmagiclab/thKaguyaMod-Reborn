## 用户实测反馈修复（阶段 4-6 渲染 + 阶段 5 GUI 测试后）

### 已修复（commit 33c7e42）
- **伞面/符札/摆锤渲染黑色**：根因是 RenderYuukaParasol / RenderSpiritualStrikeTalisman / RenderPendulum 的 `quad()` 里 `.color(1, 1, 1, 1)` 用了 **int 字面量**（VertexConsumer.color(int,int,int,int) 范围 0-255），RGB=1 几乎全黑。改 `.color(255, 255, 255, 255)`。摆锤"无模型"其实是黑到看不见。
  - **关键教训**：VertexConsumer.color 有 int(0-255) 和 float(0-1) 两个重载，字面量 `1` 会命中 int 版本=黑。正确参考 RenderItemBillboard 用 `.color(255,255,255,255)`。
- **摆锤 lang key 缺失**：`thKaguya.msg.pendulum1/2/3` 未在 5 个 lang 文件定义，补上（原版文案）。
- **迷你八卦炉无伤害不破坏地形**：Master Spark 激光 special=EXPLOSION01(70)，但 1.20.1 迁移时把原版 EntityTHShot 硬编码基础特效 switch（FIRE/EXPLOSION01/WIND01 + blockHit 的 BOUND01-04/EXPLOSION01）整个丢弃，只留 SpecialShotRegistry（ISpecialShot 符卡特殊弹）分发。
  - 修复：EntityTHShot.entityHitSpecialProcess 补 FIRE(点燃)/EXPLOSION01(爆炸3.0)/WIND01(击退) switch；blockHitSpecialProcess 补 EXPLOSION01(爆炸5.0)。EntityTHLaser 重写了 hitCheck/onImpact 但没调这两个方法，也补上调用。
  - BOUND01-04 反弹（bound 方法）仍缺，暂消弹（已知延后）。
  - **爆炸 API**：1.20.1 是 `Level.ExplosionInteraction`（NONE/BLOCK/MOB/TNT），`level().explode(src,x,y,z,r,isFire,interaction)`；不是旧 `Explosion.BlockInteraction`。
