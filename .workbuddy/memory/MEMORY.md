## 铁律（完整 57 条见 `移植任务书.md`「关键迁移约定」，此处只列最贵重的坑）
1. **资源标识符全小写**（文件名+目录名）；`static final ResourceLocation` 类加载即校验，大写→启动崩溃。
2. **贴图目录必须 `textures/item/` 与 `textures/block/`（单数）**。复数目录→实体渲染正常但物品模型缺材质（指纹：latest.log 的 `Missing textures in model`）。符卡 35 张卡面曾因此全缺材质（d983d32 修）。
3. **实体三大注册缺一不可**：EntityType + EntityAttributeCreationEvent + EntityRenderer。
4. **EntityType 必须沿构造链显式传递**，否则 getType() 全错（服务端子类/客户端父类）。
5. **yaw 两套约定（勿再改错）**：弹幕/激光 yaw 来自 `atan2(vx,vz)`（= MC yaw 相反数）→ 渲染写 `Axis.YP.rotationDegrees(yaw)` **绝不加 180**；道具实体 yaw 是 vanilla 约定 → 保留 `180 - yaw`。判据：yaw 来自 atan2 → 裸 yaw；vanilla → 180-yaw。魔炮判据：光柱须穿过迷你八卦炉两枚同心圆环中心。
6. **面向相机的 billboard 必须用 NoCull 系 RenderType**（顶点序左下→右下→右上→左上在该坐标系被判裏面，cull=整片剔除→完全不可见）。3D 手工几何（kunai/arrow/crystal）原版即单面剔除，保持 Cull。
7. **弹幕混合模式**走 `client/render/THRenderTypes.java`：加性=`(SRC_ALPHA,ONE)`；発光=`(ONE,ONE_MINUS_SRC_COLOR)`；幽霊弾=`(ONE,ONE)`；`depthWrite`=glDepthMask；全亮=uv2(FULL_BRIGHT)；白芯层=cutout。`RenderStateShard` 静态字段 protected 但内部 shard 类与构造全 public → 自建 RenderType 无需 AT/Mixin。
8. **激光/弹幕命中搜索范围按到达距离伸展**：`getHitCheckReach()` 默认 1.0，激光覆写 `getLaserLength()+getShotSize()`（否则激光零伤害，c85ea86）。
9. **SetLaser 蓄力期光束 1/10 粗细**（anim<0 && instanceof EntityTHSetLaser）。
10. **`ignoreFrustumCheck=true` → 构造里 `this.noCulling=true`**。原版清单：SpellCardCircle/SakuyaStopWatch/SakuyaWatch/SpiritualStrikeTalisman/YuukaParasol/Rumia/EntityTHLaser。
11. **覆写 `rideTick()` 必须自己驱动 `tick()`**（`if(this.canUpdate()) this.tick();`），否则实体永不 tick（e3a08eb）。
12. **`getLightEmission`≠`getBlockLightValue`**：后者对应 `level.getBrightness(LightLayer.BLOCK,pos)`（赤石蓄光曾恒 0）。
13. **追踪弹改 angle 不够**：须按当前速率重定向速度并同步 `lastShotMotionX/Y/Z`（tick() 每 tick 先恢复 lastShotMotion）。
14. **`EntityTHShot.angle` 未同步**，客户端恒 (0,0,0)，渲染/客户端逻辑不能用它。
15. **1.20.1 射线选择看 `isPickable()`**（原版 canBeCollidedWith）。
16. **禁止运行期 new Item/Block 实例**（intrusive holder 启动失败）→ `SpecialShotRegistry` 存实例（1e9815d）。同理 `RegistryObject#get()` 不能在 commonSetup 调。

18. **流体**：放置后 `((ServerLevel)level).getFluidTicks().clearArea(...)` 撤销预约才静止；移除用 `setBlock(pos, AIR, Block.UPDATE_ALL_IMMEDIATE)`（removeBlock 对流体是空操作）。
19. **禁大范围扫描清测试残留**（曾误删 141309 天然水域方块）；只清自己记录的坐标。

23. **玩家背包的 `Item.inventoryTick` 在移动之前调用**（`7d4bb6c`）：javap 实测 `Player.tick()` 中 `Inventory.tick()` 在 offset 113、`LivingEntity.tick()` 在 140，所以 `getDeltaMovement()` 拿的是上一 tick 末尾乘过摩擦的值（地上 6.0×0.546≒3.28），`getBoundingBox()` 也是移动前的位置。1.7.10 `onUpdate` 却在移动之后 → 照抄「速度门限 + 当前位置朝前伸判定盒」的写法会漏判整段位移（楼观剑突进斩击全空）。修法：用 `getX()-xo`（前 tick 实际位移）兜底门限，判定盒 `move(-d).expandTowards(2d).expandTowards(motion).inflate(1.0)`。
24. **1.7.10 的反射混合不看顶点 alpha**（`7d4bb6c`）：`GL_ONE, GL_ONE_MINUS_SRC_COLOR` 只取 RGB，发光层若画在不透明本体之后，会把本体盖成一块近乎不透明的色盘（御币弹阴陽玉被红色 halo 盖死 → 看着像「巨大橙色子弹」）。1.20.1 的 `entity_translucent` 着色器把 rgb/alpha 分开输出，改「光效在前、本体在后」即可。另：临时诊断日志验完必须删干净（本次清了 5 处，自检 `grep -rn "一時診断|\[TH\]|\[thkaguya\]" src/main/java`）。
25. **子类的便宜构造必须自己传 EntityType**（`7c1de2b`）：`EntityTHShot(Level, LivingEntity, ...)` 内部写死 `this(THKaguyaEntities.TH_SHOT.get(), ...)`（`EntityTHShot.java:163-173`）。`EntityOnmyoudama` 复用它 → 服务端实体类型是 `TH_SHOT` → 刷怪包让客户端生成**基类 `EntityTHShot`** → `ClientRenderRegistry.java:181` 给 `ONMYOUDAMA` 注册的 `RenderOnmyoudama` 成了死代码，画面一直走通用 `RenderTHShot`（「巨大的橙色子弹」）。修法：子类加 `EntityType<?>` 首参构造转发基类 `EntityTHShot(EntityType<?>, Level, ...)`，便宜构造 `this(THKaguyaEntities.<自己>.get(), ...)`。自检 `javap -p -c <jar> <实体类> | grep TH_SHOT`。**「换了实现症状一字未变」= 那段代码根本没执行**，先查对象是哪个类/哪个 EntityType，别再改渲染细节。

38. **「全方位弹」必须绕竖直轴转，库里的 `createRingShot` / `createCircleShot` 都是绕视线轴**（`19ffba1`，蓬莱玉枝潜行）：`createWideShot` 的旋转轴是 `getVecFromAngle(-yaw, -pitch + 90F)`（`THShotLib.java:668`，把视线向上翻 90°），所以它把**视线向量**在「视线⊥平面」里转一圈——平视时是一面竖着的圆墙，弹全往前飞、身后没有弹；`createRingShot` 更是拿 `getVecFromAngle(yaw, pitch + ringSpan/2)` 当基准向量绕视线轴转，`ringSpan = 0` 时基准向量与轴重合 → 绕轴旋转无效 → 全部弹同一方向（实机就是「向前的一条线」）。要水平 360° 全方位：`dir = angle(getYRot(), 0)`、`axis = new Vec3(0,1,0)`，逐发 `getVectorFromRotation(axis, dir, base + k*360/shotNum)` 再 `createShot(..., slope 0F, rotate = axis, 0F, 9999, ...)`。教训：参数调不动时先算几何，别连改三轮。
39. **时停「天空反色」= `ONE_MINUS_DST_COLOR` 反色混合；1.20.1 用 `AFTER_SKY` 全屏 quad 复刻，纯白负片会棕、事件给的 PoseStack 会变成半边的墙**（`6121db4` → `6343b7e`，咲夜怀表）：原版球壳 `glBlendFunc(ONE_MINUS_DST_COLOR, GL_ZERO)` + 全白 `DarkTexture.png`，`dst' = src*(1-dst)`，画在地形之前 + 被地形遮挡 → 观感「只有天空翻负片」；原版 alpha 淡出是死代码（无 `SRC_ALPHA`）＝硬切。三个坑：① 用事件 `PoseStack` 画 quad 会被相机旋转带成竖直平面 → 只有一半天空变色，必须改成 GUI 那套「正射影 + 单位模型视图」（`setProjectionMatrix(new Matrix4f().setOrtho(...), VertexSorting.ORTHOGRAPHIC_Z)` + `getModelViewStack()` push 后 `pose().identity()` + `applyModelViewMatrix()`，画完 pop + `setProjectionMatrix(旧, DISTANCE_TO_ORIGIN)`；1.20.1 没有 `setModelViewMatrix`）；② `AFTER_SKY` 时帧缓冲里只有天空，地形/实体/云在其后画 → 天然只反天空；③ 纯白负片对蓝天必然橙褐，改「青紫负片」：第 1 遍 `ONE_MINUS_DST_COLOR`/`ZERO` + 顶点色 TINT → `dst' = TINT*(1-dst)`，第 2 遍 `ONE`/`ONE` + GLOW → `dst' += GLOW`。**别用 `shaders/post/invert.json`**（整屏反色 + 抢 `gameRenderer.postEffect`）。
40. **`Long.MIN_VALUE` 当「从未发生」哨兵 + `now - sentinel > 1` 会溢出成负数 → 条件恒假、效果从进游戏就常亮**（`6343b7e`，时停反色第一次交付）：`getGameTime()` 是小正数，减 `Long.MIN_VALUE` 直接溢出成负值，于是「还没见过怀表」被判成「刚见过」，天空一进游戏就变色。正解：每个 tick 先置 `false`、命中才置 `true` 的布尔量（`active`），语义即「本 tick 有停止空间」，天然硬切、无溢出面。
41. **1.20.1 的「死了又活」= `LivingDeathEvent.setCanceled(true)` + `setHealth(max)`，不是 1.7.10 的 `isDead = false`**（`43ebc31`，扩展道具复活）：`LivingEntity.die()` 第一条语句就是 `ForgeHooks.onLivingDeath`，返回 true 直接 return（`dead` 都不置位）；`hurtResistantTime` → `invulnerableTime`（`Entity` 的 public 字段）；`inventory.mainInventory[i]` → `getInventory().items.get(i)`；事件两侧都 fire，必须自判 `isClientSide`。同批补的三处 `danmakuRemove` 都在服务器端执行，且 `"Other"` 会连中心那发自己一起消（原版如此）。
42. **「掉的怪不对」先查原版分支与概率，别急着改代码**（Fafrotskies 复核）：`pattern <= 90` 分支原版就是**普通** `EntityCreeper`；`EntityDanmakuCreeper` 仅在 12/25 生成、1/1–1/3 换核弹；且原版弹幕苦力怕**没有自定义模型/贴图**，与普通苦力怕肉眼相同，只能看爆炸是否撒弹幕。
43. **1.20.1 的村民 = `PoiType` + `VillagerProfession` + `VillagerTradesEvent` 三件套，且谓词里只能用 `ResourceKey`**（`ae3eae7`，霖之助）：`PoiType` 用 `DeferredRegister` 就能被识别（`PoiTypes` 的 `<clinit>` 读 `GameData.getBlockStatePointOfInterestTypeMap()`，Forge 注册后重建该 map，`ServerLevel#onBlockStateChange` 走 `PoiTypes.forState`），**不需要反射注入**；`VillagerProfession(String, Predicate<Holder<PoiType>>, Predicate<Holder<PoiType>>, ImmutableSet<Item>, ImmutableSet<Block>, SoundEvent)` 的两个谓词必须 `holder -> holder.is(KEY)`——写 `holder.is(REG.get())` 在注册期是 null 会 NPE；职业会被 `Villager` 的构造/读档/失站改回 `none`，必须 override `setVillagerData` 强制写回；交易用 `event.getTrades().computeIfAbsent(1, k -> new ArrayList<>()).add((trader, random) -> new MerchantOffer(buying, selling, 7, 0, 0.0F))`（原版 `MerchantRecipe(buying, selling)` 默认 maxUses 7 / xp 0 / 不涨价）。**原版 `CommonProxy#registerChestItem()` 是空方法**（`extract/sources/java/thKaguyaMod/CommonProxy.java:658-661`），`ItemUchide#getChestGenBase` 从未被调用 → 「万宝槌进箱子」属有意新增，用 `LootTableLoadEvent` + `LootPool.lootPool().name(...)` 加池并靠池名判重。
