### 3. 分析框架

构建了智能化的可行性分析框架：

#### 检测的关键 API（1.7.10 → 1.20.1）

**高难度迁移**:
- `GL11.*` - 固定管线渲染（已移除）
- `Tessellator` - 旧版渲染系统
- `IIcon` - 旧版材质系统
- `registerBlockIcons` - 材质注册

**中等难度迁移**:
- `GameRegistry` - 注册系统（改为 DeferredRegister）
- `IMessage` - 网络协议（完全重写）
- `EntityRegistry` - 实体注册
- `cpw.mods.fml` - 包名变更

**低难度迁移**:
- `setBlockName/setUnlocalizedName` - 简单的 API 替换
- 事件系统 - 仅需小幅调整

#### 评分系统

- **难度评分**: 0-200 分
  - 0-50: 可行性高（简单）
  - 50-100: 可行性中等
  - 100-150: 可行性低（困难）
  - 150+: 可行性很低（需要完全重写）

- **工时估算**: 基于检测到的问题自动计算

## 🎓 Minecraft 版本差异概述

### 1.7.10 → 1.20.1 的主要变化

#### 核心系统变化

**1. 注册系统**
- 旧: `GameRegistry.registerBlock/Item`
- 新: `DeferredRegister` + `RegistryObject`

**2. 方块状态**
- 旧: 元数据（metadata）系统
- 新: 完整的 BlockState 属性系统

**3. 渲染系统**（最大变化）
- 旧: 固定管线（GL11）+ Tessellator
- 新: 现代化管线 + PoseStack + VertexConsumer

**4. 材质系统**
- 旧: IIcon + registerIcons
- 新: JSON 模型 + 资源包系统

**5. 网络通信**
- 旧: IMessage + SimpleNetworkWrapper
- 新: 新的网络协议系统

**6. 数据存储**
- 旧: NBT 手动处理
- 新: Codec 系统 + 数据组件

#### Java 版本要求
- 1.7.10: Java 7/8
- 1.20.1: Java 17+
