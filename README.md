# 辉夜姬的五难题·重铸 / THKaguya Reborn

![Minecraft](https://img.shields.io/badge/Minecraft-1.20.1-38bdf8?style=flat-square)
![Forge](https://img.shields.io/badge/Forge-47.4.28%2B-e11d48?style=flat-square)
![Java](https://img.shields.io/badge/Java-17-f59e0b?style=flat-square)
![Release](https://img.shields.io/badge/release-beta--0.1.0-a855f7?style=flat-square)

把 2014 年的东方 Project 同人 Mod **「五つの難題MOD+ ver2.90.1」**（Minecraft 1.7.10 Forge）整体移植到 **Minecraft 1.20.1 Forge** 的非官方项目。

原作者的代码、美术、音效、数值全部保留原样；不能一比一搬过来的部分（GL 固定管线、`Item` 子类型、GUI API、成就/进度、网络同步）按 1.20.1 的模型重写，每一处差异都记录在案。

## 内容规模

| 项 | 数量 |
|---|---|
| 物品 | 118（含 14 个刷怪蛋） |
| 方块 | 3（弹幕工作台 / 激光弹幕工作台 / 8 色小神霊） |
| 实体 | 48 |
| 符卡 | 35 |
| 配方 | 109 |
| 村民交易 | 8 |
| 语言 | 5（简体中文 / 繁体中文 / 英文 / 日文 / 韩文，各 236 键） |

包含伪物五件（蓬莱玉枝、龙颈之玉、佛御石之钵、火鼠的皮衣、燕的子安贝）、东方角色武器与道具、弹幕合成系统、符卡宣言、Boss 战与小神霊/村民交易。

## 安装

1. 安装 **Minecraft 1.20.1** + **Forge 47.4.28**（或更高的 47.x）。
2. 把 `thkaguya-beta-0.1.0.jar` 放进 `mods/` 目录。
3. 启动游戏。首次启动会在 `config/` 生成 `thkaguya-common.toml`。

**客户端与服务端都要装**：本模组含自定义实体、渲染层与音效事件。

> ⚠️ 版本号写作 `0.1.0-beta`（Forge 要求以数字开头），对外发布文件名仍为 `thkaguya-beta-0.1.0.jar`。

## 从源码构建

需要 **JDK 17** 与 **Gradle 8.x**（仓库未附带 wrapper，请直接用系统 `gradle`）：

```bash
cd thkaguya-1.20.1
gradle build
# 产物：build/libs/thkaguya-0.1.0-beta.jar
```

首次构建会下载 ForgeGradle 6 与 Minecraft 1.20.1 依赖，需要数分钟。

## 实验性玩法：妖器化（万宝槌）

原作者的「万宝槌改造台」在 1.7.10 里被整段注释掉了（类还在、界面还在，但没有任何入口）。本移植把它做成了**默认关闭的实验性功能**：

- 在 Mods 列表 → `辉夜姬的五难题·重铸` → **Config** 里打开「万宝槌·妖器化」；
- 第一次开启会弹出确认页（可勾选「不再提示」），文案即原作者的「这是已经神隐（被原作者注释掉）的功能，你确定要开启吗？」；
- 开启后**潜行 + 右键**万宝槌打开「妖器化」界面，把素材炼成对应妖器（阴阳玉→渴望鲜血的阴阳玉、隙间→隙间的折叠伞、楼观剑→楼观旋风刃）；
- 开启后进入游戏会获得挑战进度「在倒悬的天守阁中」。

配置由服务端判定，多人服务器需要管理员开启。

## 已知问题

公测版功能覆盖完整，但与 1.7.10 仍存在一批**行为 / 数值差异**，完整清单见 [`移植检查报告-复核轮.md`](移植检查报告-复核轮.md)（12 章、245 条）。

代表性的几条：

- 少数武器/工具的耐久或攻击力与原版不同；
- 弹幕会命中动物与村民；贴墙目标可能免伤；追踪弹比原版更「咬人」；
- 固定激光被方块挡住后会永久变短；激光撞弹直接消掉对方；
- 灵梦 / 咲夜 / 神子三位 Boss 暂不掉落 power / point 素材；
- 时停不冻结弹幕生物。

**有意为之的改动**（不算缺陷）：Boss 血条改用 1.20.1 的 `ServerBossEvent`；自然生成改为 `biome_modifier` + 配置门控；万宝槌「妖器化」为新增实验内容；星弹凹角从原版的 `1.2` 收深到 `0.8`（原版凹角仅 40% 深，远看像五边形）。

## 移植原则

1. **数值与手感优先对齐原版**：伤害、弹数、角度、冷却、耐久等一律照抄 1.7.10 源码。
2. **渲染逐 form 重写**：1.7.10 用 GL 固定管线逐顶点画 quad，1.20.1 只能按 `RenderType` + `VertexConsumer` 重写；透明/混合/剔除语义逐项对齐（含 alpha test、加算、两面渲染）。
3. **差异必须可追溯**：任何不能一比一移植的地方都在报告里写明原因与替代方案。
